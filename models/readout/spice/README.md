# ASAP7 transient-noise proof — toolchain & test decks

Transistor-level SPICE for the single-slope readout (`../ss_readout_mc.py`),
per the "ASAP7 COMPARATOR + RAMP TRANSIENT-NOISE PROOF" directive.

## Toolchain (stood up from nothing, no root, WSL2 Ubuntu 26.04)

No SPICE simulator, no PDK, and no `sudo` were available. What was built:

| component | how |
|---|---|
| **ngspice 44** | built from `git.code.sf.net/p/ngspice/ngspice` (branch `ngspice-44`), `./configure --prefix=$HOME/opt/ngspice --with-x=no --disable-debug --enable-osdi --without-readline --enable-openmp` → `config.log`: *"OSDI features included"*. bison/flex/autotools via a `micromamba` conda-forge env (no root). Debian/conda ngspice binaries were unusable: neither ships BSIM-CMG (level 72) and neither enables OSDI. |
| **OpenVAF 23.5.0** | prebuilt static linux-amd64 binary. |
| **BSIM-CMG 111** | `bsimcmg.va` from `github.com/dwarning/VA-Models` (`code/bsimcmg/vacode111`), compiled to `bsimcmg.osdi` with OpenVAF (module name `bsimcmg_va`). |
| **ASAP7 PDK r1p7** | `github.com/The-OpenROAD-Project/asap7`, submodule `asap7_pdk_r1p7`; HSPICE cards `models/hspice/7nm_{TT,SS,FF}.pm` (BSIM-CMG L72 v107, devices `nmos/pmos_{lvt,rvt,slvt,sram}`). |

### ASAP7 -> OSDI transform (`tb/7nm_{tt,ss,ff}_osdi.pm`, regenerated by the harness)

```
.model <name> nmos level = 72   ->   .model <name> bsimcmg_va type=1
.model <name> pmos level = 72   ->   .model <name> bsimcmg_va type=0
```

ngspice then warns and ignores `version, coremod, capmod, nseg` (not in the
OpenVAF build of CMG 111) — immaterial for this study (DC/transient large-signal
+ thermal). **OSDI instances must use the `N` device prefix, not `M`/`P`.**
`pre_osdi bsimcmg.osdi` goes **inside `.control`**; paths are lowercased by
ngspice so the `.osdi` is kept as a lowercase relative name in `tb/`.

## Reproduce

```bash
export MAMBA_ROOT_PREFIX=$HOME/mm
NG=$HOME/opt/ngspice/bin/ngspice
cd tb && $NG -b smoke2.cir            # ASAP7 NMOS Id(Vgs=Vds=0.7, nfin=7) ~ 340 uA, gm ~ 0.78 mS
cd ../harness
for m in tt ss ff; do for t in -40 27 125; do
  python3 ss_spice.py ramp --tag c_${m}_${t} --corner-model $m --temp $t --vbs 0.512
done; done
```

`I_PD` scaling held everywhere: `I_PD,RMS = 0.74 uA`, `I_PD,FS = 4.45 uA`,
`Q_FS = 1.137 pC`, `V_FS = 568 mV`, ramp span 0–0.71 V (1.25xFS), `T_ramp`
target 171 ns (=> 4.15 mV/ns).

## Decks (`tb/`)

| file | purpose | status |
|---|---|---|
| `ramp_fall.cir` | NMOS current-sink falling ramp (best headroom vs the 0.8 V rail) | **run, 9 PVT corners** |
| `ramp.cir`, `ramp_casc.cir` | rising single-PMOS / PMOS-cascode ramp | run; cascode has no headroom into a 0.72 V node from 0.8 V |
| `preamp_lat.cir` | auto-zeroed NMOS-pair pre-amp (R loads) + StrongARM latch | **instantiates & simulates**; stimulus wiring + latch balance need bring-up — thermal/offset/energy NOT yet measured |
| `preamp_only.cir` | pre-amp DC gain / op-point extraction | stimulus miswired — numbers not yet trustworthy |

## Proven vs. pending

* **Proven:** the full ASAP7/BSIM-CMG/OSDI/ngspice flow runs; devices bias
  physically; the current-on-cap **ramp** (gates e, f) is measured across
  TT/SS/FF x −40/27/125 °C — data in `gcb-papers/data/readout/spice/`.
* **Pending (needs analog bring-up, not more tooling):** comparator
  input-referred thermal at the crossing (a); residual 1/f (b — ASAP7 ships
  **no** flicker parameters, so this can only ever be a generic-Kf estimate);
  3-sigma V_os mismatch MC (c — ASAP7 ships no statistical model; needs a
  Pelgrom `dvtshift` overlay); energy/decision (d).
